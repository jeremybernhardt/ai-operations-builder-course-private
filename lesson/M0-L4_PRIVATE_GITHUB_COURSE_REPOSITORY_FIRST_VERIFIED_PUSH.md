## Concepts taught

- A local repository is the working source on the Mac; `origin` is a saved address for a separate GitHub repository.
- A private GitHub repository is still external cloud state. Privacy limits who may access it; it does not erase metadata or remove credential, permission, account, or provider risk.
- Authentication proves the CLI may act as an account. Authorization defines what action Jeremy has approved. They are separate controls.
- A successful push proves only that Git transferred something. It does not by itself prove the intended owner, visibility, branch, files, metadata, secrets boundary, or logical correctness.
- An independent clone and reconstruction test verifies that the remote source is usable without hidden reliance on the current folder or conversation.
- The Course Portal remains a companion for course navigation and the preserved prototype; it is not the authoritative state store and does not count as work-dashboard evidence.
