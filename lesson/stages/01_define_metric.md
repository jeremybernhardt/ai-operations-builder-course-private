# Stage 1 — Define the operating metric

Checkpoint: `P0-C1`  
Status: Completed with substantial assistance; available in review mode

## Situation

Finance experts submit synthetic reasoning tasks. Reviewers accept the work, request revisions, or reject it. An operations manager wants to know how often work is ready on its first review without revision.

The raw review-event data contains duplicate logical reviews, a missing outcome, and reworked submissions. A calculation made before these cases have explicit policies can be internally consistent and still answer the wrong question.

## Learning objectives

1. Explain what first-pass acceptance tells an operations manager.
2. Distinguish review-event rows from unique work items.
3. Set explicit policies for duplicates, missing outcomes, and rework.
4. State a numerator, denominator, formula in words, and supported decision.

No SQL or final dataset calculation is required at this checkpoint.
