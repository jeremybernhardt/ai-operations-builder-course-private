This is the learner entry point. You do not need to understand the other files in this folder. They keep the course reproducible and preserve its source of truth.

Your one-time tools are ready.

Node.js 24.18.0, npm 11.16.0, Python 3.13.14, and Git 2.50.1 were installed and verified during guided setup and Module 0. Do not reinstall them.

Open the private course site

  1. Open Terminal with Command + Spacebar, type Terminal, and press Return.
  2. Type cd followed by one space. Do not press Return yet.
  3. Drag this entire course folder from Finder onto Terminal. Then press Return.
  4. Enter the single course-start command below and press Return.
npm run course

The first start may download the exact supporting components listed by the course bundle. They remain inside this folder. The command then prepares the preserved synthetic practice data and starts a site available only from your Mac.

Open the address labeled Local, normally http://localhost:5173/. Keep Terminal open while using the site.

When you finish

The final site stage explains what you completed, what comes next, and how to begin the next lesson in a fresh chat. The handoff and next-chat prompt are continuity files for that new conversation—not extra lesson reading.

Return to Terminal and press Control + C. That stops the local site. It does not delete your course files or uninstall anything.

Privacy boundary: use only the Local address. Do not start a tunnel or publish the site.

What the site does—and does not do

The site presents the Course Portal, preserved synthetic prototype data, and guided lesson interactions. It facilitates lessons; it is not the work dashboard you will later learn to build. Lesson review choices may be stored only in this browser on this Mac so a refresh does not erase them.

It does not create an account, upload the dataset, publish anything, or edit authoritative progress. Verified progress remains in the canonical course files.

The technical README is available for troubleshooting and verification, but it is not required reading for the learner.
